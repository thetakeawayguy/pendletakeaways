How to approve a food recommendation

This page explains the owner-only publishing process. Customer submissions arrive privately through the existing form service and are not published automatically.

Review and publish in four steps

  1. Check the new submission in your Formspree notification email or dashboard.
  2. Check that the takeaway and dish are correct, the recommendation is appropriate, and permission to publish was given. Remove any private details.
  3. Open Publish approved dish recommendation on GitHub. Sign in to your repository account, select Run workflow, and fill in the approved dish details.
  4. Select the green Run workflow button. When the workflow finishes and GitHub Pages deploys, the approved dish will appear on the appropriate takeaway page.

Currently supported takeaway pages: Mansha and Adams Curry House. Other takeaway pages can be connected as we expand.

Important

Only the repository owner or someone with suitable GitHub permissions can publish. This is a manual approval process, not an automatic connection between Formspree and GitHub. If the GitHub workflow fails, nothing is published; check the Actions run for details.
